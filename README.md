# Galaxy Classifier — класифікація галактик за даними SIMBAD

У цьому репозиторії зберігається настільний Python-додаток **Galaxy Classifier** і допоміжні скрипти для впорядкування зображень галактик за каталоговими морфологічними типами.

> **Примітка:** назва репозиторію `wolf-numbers` історична; основний графічний застосунок у ньому — класифікатор галактик, а не калькулятор чисел Вольфа.

## Можливості

- Вибір папки із зображеннями або ZIP-архіву.
- Розпізнавання назв галактик у назвах файлів (`NGC`, `IC`, `M`).
- Пошук морфологічного типу в SIMBAD через `astroquery`.
- Розкладання копій зображень по папках відповідних типів.
- Формування `classification_report.csv`.
- Графічний інтерфейс на Tkinter із журналом, таблицею результатів і прогресом.

Типи **не визначаються нейромережею за пікселями**: програма використовує метадані каталогу SIMBAD. За відсутності назви чи типу використовується папка `Unknown`.

## Основні файли

| Файл | Призначення |
| --- | --- |
| `galaxy_classifier_app.py` | Основний GUI-додаток. |
| `classification.py` | Консольний варіант класифікації; використовує жорстко задані шляхи. |
| `galaxy.py` | Допоміжний скрипт завантаження зображень. |
| `latex table.py` | Формування рядків LaTeX із `classification_report.csv`. |
| `GalaxyClassifier.spec` / `GalaxyClassifier_fixed.spec` | Конфігурації PyInstaller для збирання програми. |
| `galaxy_classifier.ico` | Іконка додатка. |

## Встановлення та запуск

Для запуску з вихідного коду потрібен Python 3.10+:

```bash
python -m pip install astroquery
python galaxy_classifier_app.py
```

Tkinter зазвичай постачається разом із Python на Windows. Для роботи із SIMBAD потрібен інтернет.

У вікні програми оберіть папку або ZIP із зображеннями, вкажіть папку результатів і запустіть класифікацію.

## Результати

```text
classified_galaxies/
├── <морфологічний тип>/
│   └── зображення галактик
├── Unknown/
└── classification_report.csv
```

Поля звіту: `file`, `galaxy_name`, `morphology`, `folder`, `description`.

## Збирання Windows-додатка

За потреби можна використати одну з наявних конфігурацій:

```bash
python -m pip install pyinstaller
pyinstaller GalaxyClassifier.spec
```

Конфігурація може потребувати налаштування залежно від версій Python та бібліотек. Згенеровані файли у `build/` не є вихідним кодом.

## Зауваження

Автоматична класифікація залежить від наявності й якості запису в SIMBAD. Результати варто перевіряти, особливо для галактик зі складною або неоднозначною морфологією.
